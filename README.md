# eight-dollars

eight-dollars can help you tell the difference between actual verified accounts and twitter blue users. Just install the extension and see the difference.

Original by [Will Seagar](https://twitter.com/willseagar), [Walter Lim](https://twitter.com/iWaltzAround), and [Ilia Sidorenko](https://twitter.com/noway421) at https://github.com/wseagar/eight-dollars. Modified by ahmedaliashraf (https://github.com/ahmedaliashraf) to fix issues with it not working on firefox. FOR PERSONAL USE ONLY.
